# Chapter Objectives and Technical Requirements

In this chapter, we will cover the following topics. 

1. Filesystem Content
2. Transfering the filesystem to the target device
3. Creating a boot ```initramfs``` 
4. Configuring user accounts
5. Managing Device Nodes 
6. Configuring the Network
7. Create Fylesistems with device tables
7. Mounting the root Filesystem with NFS
8. Using TFTP to load the kernel

# Technical Requirements.

- A Linux based host system
- A micro-SD card and reader
- The micro-SD card formatted prepared to boot ZYBO as in Ch3 of this repository. 
- ```zImage``` and ```dtb``` files for ZYBO (built in Ch4 of this epository).
- ZYBO development board.
- Ethernet cable for NFS and TFTP.
