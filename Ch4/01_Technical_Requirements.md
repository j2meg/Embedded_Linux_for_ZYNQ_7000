# Configuring and Building the Kernel. 
## Technical Requirements

1. Linux based host system
2. CrossTool-NG generated toolchain for Zybo created on Ch2 directory. 
3. Micro-SD Card and Micro-SD Card reader. 
4. The micro-SD card must to have the u-boot files built in Ch3 directory. 
5. ZYBO Development Board. 
6. Micro-USB to USB type A to attach ZYBO to the Host PC.
